## 🛠️ Технологии

| Технология | Что использовалось |
|------------|-------------------|

## 📦 Функционал

### Задачи
- ✅ Добавление, редактирование, удаление задач
- ✅ Отметка о выполнении
- ✅ Фильтрация по статусу (все/активные/выполненные)
- ✅ Сортировка по дате и приоритету
- ✅ Поиск по названию
- ✅ Сохранение в localStorage

### Привычки
- ✅ Добавление привычек
- ✅ Отметка выполнения на сегодня
- ✅ Подсчёт текущей серии (streak)
- ✅ Визуализация последних 7 дней

### Навигация
- 🧭 SPA-роутинг на History API
- 📱 Адаптивное боковое меню с бургером
- 🎨 Подсветка активной страницы
